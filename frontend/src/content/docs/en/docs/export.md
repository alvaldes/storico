## JSON and Markdown export

Export your tasks to JSON or Markdown with one click. Compatible with your existing workflow.

Open the export page, select a workspace, choose **JSON** or **Markdown**, and click **Download**. The backend returns the file as a download: JSON as an array of tasks, Markdown with one section per story. An empty workspace downloads valid but empty content.

These are the only two formats available — CSV and XML are not supported.
