Start here:

- [Import from CSV](/en/docs/story-import) — create many stories at once, and every reason a file is refused.
- [LLM providers](/en/docs/llm-providers) — Ollama, OpenAI, Anthropic, Gemini, custom providers, and the fields each one needs.
- [Export](/en/docs/export) — download your tasks as JSON or Markdown.
- [Kanban board](/en/docs/kanban) — the task states, the moves the server allows, and what is editable.
- [Extraction versions](/en/docs/extraction-versions) — what re-extracting a story does to its tasks.
- [Historical context](/en/docs/embeddings-rag) — where the examples in an extraction prompt come from.
- [Roles and permissions](/en/docs/roles-permissions) — who may do what in a workspace.
- [API reference](/en/docs/api-reference) — every endpoint, generated from the application itself.
