## Getting started

1. **Run Storico locally** — clone the repository and follow the setup guide in the README.
2. **Configure your LLM** — choose between Ollama (local), OpenAI, Anthropic, or Gemini. Ollama needs no API key, but every provider still needs a model.
3. **Create a project** — organize your user stories into projects.
4. **Paste a user story** — use the standard "As a… I want… so that…" format.
5. **Extract tasks** — let AI break down your story into structured tasks.
6. **Review and export** — edit tasks as needed and export to JSON or Markdown.

For the exact format Storico expects, see [User story format](/en/docs/story-format).
