## Exportación a JSON y Markdown

Exporta tus tareas a JSON o Markdown con un clic. Compatible con tu flujo de trabajo existente.

Abre la página de exportación, selecciona un espacio de trabajo, elige **JSON** o **Markdown** y haz clic en **Descargar**. El backend devuelve el archivo como descarga: JSON como un arreglo de tareas y Markdown con una sección por historia. Un espacio de trabajo vacío descarga contenido válido pero vacío.

Estos son los únicos dos formatos disponibles: CSV y XML no están soportados.
