---
title: Formato de historia de usuario
description: El formato estándar que Storico espera para las historias de usuario.
---

Storico funciona mejor con historias en formato estándar:

```text
As a(n) [role], I want [feature], so that [benefit]
```

Ejemplo:

> "As a user, I want to reset my password so that I can regain access to my account."
