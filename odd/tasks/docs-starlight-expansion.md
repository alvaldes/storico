## Problem

The Starlight site carried ten pages per locale. Eight of them were written in `docs-content-v2`
from the code, but they deliberately stopped at one page per feature, at the depth already
verified: none of them enumerated configuration fields, per-provider requirements, limits, or the
error codes the server answers with. Two pages were materially incomplete:

- `llm-providers` (15 lines) named four providers and nothing else — no field per provider, no
  custom providers, no model discovery, no readiness gate.
- CSV story import had **no page at all**. It shipped in `v0.8.0` and was explicitly deferred by
  `odd/tasks/docs-content-v2.md` (*"The CSV import page — Still blocked: follow-up 11 … open"*).
  The owner has now asked for it, so the page documents the **code's contract**, not a production
  claim; follow-up 11 of `odd/tasks/csv-story-import.md` stays open and untouched.

## The rule that governed every page

**The source of truth is the code — never `AGENTS.md`, never `docs/`, never the landing copy.**
Every claim carries a `path:line` source in the evidence log below. No claim without a source.

## Findings recorded, not fixed

1. **`POST /api/v1/llm/test` is not workspace-scoped.** Any authenticated user can make the server send a request to an arbitrary host with an arbitrary API key (`backend/src/storico/api/routes/settings.py:146-311`). Documented factually in `roles-permissions`. Whether it should be gated is a behaviour decision for the owner.
2. **An admin's `GET /settings/llm` returns the stored API key in plaintext** (`backend/tests/test_api/test_workspace_settings_llm_config.py:390-393`). Documented factually; masking is a product decision.
3. **`csv-story-import` follow-ups 6, 10 and 11 stay open.** 11 in particular means the production composition has never carried a real upload; the new page documents the code contract only.
4. **`AGENTS.md` and `docs/deployment.md` still describe the Docker Compose dev database**, which is a known, owner-recorded drift (`AGENTS.md`, top note). Untouched here.
